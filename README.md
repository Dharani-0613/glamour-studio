# Glamour Studio Booking System
A full-stack web application for booking salon appointments. 
Users can select services, book slots, and manage appointments.
Built using Next.js (frontend) and FastAPI (backend).

Frontend (Website): https://glamour-studio1.netlify.app/
Backend API: https://glamour-studio-backend.onrender.com

# Features
- User booking system
- Admin dashboard
- Appointment management
- API-based backend

# Tech Stack
Frontend: Next.js, React
Backend: FastAPI (Python)
Deployment: Netlify (frontend), Render (backend)
